# 杭州房地产信息可视化系统

本项目是一个借助芬棱软件工厂体系生成和持续演化的数据产品工程，目标是围绕杭州市余杭区住宅小区成交量等公开房地产信息，建设一套可定时采集、结构化入库、可视化分析和辅助决策的系统。

项目形态由两部分组成：

- OpenClaw 定时工作流：定期爬取透明房产网等公开来源中关于杭州市余杭区各小区的成交量数据，清洗为结构化记录，并通过服务端录入接口写入数据库。
- 数据服务与可视化前端：提供数据库、数据录入接口、查询分析接口和面向用户的前端页面，用图表、表格和筛选工具展示小区成交走势、成交量变化和区域对比。

## 项目目标

这个系统希望帮助关注杭州房地产市场的人更精确地理解小区成交情况，尤其是余杭区不同小区的真实成交活跃度、时间变化和区域差异。

核心目标包括：

- 持续采集余杭区小区成交量相关公开数据。
- 将分散网页数据转换为稳定、可查询、可分析的结构化数据。
- 建立数据库和服务端接口，支撑 OpenClaw 工作流写入和前端读取。
- 提供可视化界面，用图表、表格、筛选和排序帮助用户观察趋势。
- 为个人购房、卖房、关注市场变化等决策提供数据参考。

## 系统组成

### OpenClaw 定时工作流

OpenClaw 工作流负责自动化采集任务。它应该支持按固定频率运行，例如每天、每周或按用户配置的时间触发。

预期流程：

1. 读取采集配置，包括目标区域、目标数据源、抓取范围和时间窗口。
2. 访问透明房产网等公开数据源，采集杭州市余杭区小区成交量相关信息。
3. 解析页面或接口返回内容，抽取小区名称、区域、日期、成交量、来源、抓取时间等字段。
4. 清洗、去重和标准化数据。
5. 调用服务端录入接口，把结构化数据写入数据库。
6. 记录本次任务的运行状态、失败节点和修复建议。

### 服务端

服务端是 OpenClaw 工作流和前端页面之间的数据中枢。

预期能力：

- 提供数据录入接口，供 OpenClaw 工作流写入采集结果。
- 管理数据库表结构和数据校验规则。
- 提供查询接口，供前端按小区、区域、日期范围、成交量等条件检索。
- 提供统计接口，支持趋势分析、排行榜、区域聚合和异常变化识别。
- 保存采集任务日志，便于追踪数据来源和排查失败。

### 数据库

数据库用于保存采集后的结构化数据和系统运行信息。

建议至少包含这些数据：

- 小区基础信息：名称、区域、板块、别名、来源标识。
- 成交量记录：小区、日期、成交量、数据来源、采集批次。
- 采集任务记录：任务时间、状态、数据源、失败原因、写入数量。
- 数据质量记录：重复数据、缺失字段、异常波动、人工备注。

### 前端可视化页面

前端页面面向最终用户，应该把数据产品做成可浏览、可筛选、可比较的分析工具。

预期页面和组件：

- 总览面板：展示近期成交活跃度、重点小区变化和整体趋势。
- 小区列表：用表格展示小区名称、区域、最新成交量、历史变化和更新时间。
- 趋势图表：展示单个小区或多个小区在不同时间段的成交量走势。
- 区域对比：对比余杭区不同板块或小区群的成交活跃度。
- 筛选与排序：支持按小区、日期、区域、成交量区间等条件查看数据。

## 初始范围

第一阶段优先完成一个可运行的最小闭环：

1. OpenClaw 可以触发一次 dry-run 或真实采集任务。
2. 服务端提供一个数据录入接口。
3. 数据库能保存一批结构化小区成交量记录。
4. 前端能展示成交量表格和至少一个趋势图。
5. 系统能记录采集失败原因和下一步修复动作。

暂不优先处理的事项：

- 覆盖杭州市所有城区。
- 建立复杂预测模型。
- 支持多人权限系统。
- 直接给出投资建议或交易结论。

## 数据边界

本项目聚焦公开房地产信息的数据整理和可视化，不绕过网站访问限制，不采集非公开、个人隐私或需要授权的数据。

采集模块应尊重目标网站的访问规则，并保留数据来源、采集时间和任务日志，方便后续核验。
