# 杭州房地产信息可视化系统 MVP

## 1. Product Intent

本系统专注于通过精细化的小区、标准化户型量价图表，以及全国宏观大盘的多维对照，辅助用户进行准确的杭州二手房置业与投资决策。

## 2. Target Users

- 关注杭州房地产精确小区成交量、成交均价及历史趋势的个人购房者与房产投资者。
- 需要对比不同板块、小区之间主力户型偏好及同比/环比数据的数据研究与行业分析人员。

## 3. Core Problem

现有房产平台（如贝壳等）在提供数据时存在以下局限性：
- 范围太广且杂，不够聚焦杭州本地的精细化需求。
- 缺乏跨小区、跨板块的直观对比分析工具。
- 历史成交量价数据展示受限，没有提供同比、环比等分析工具。
- 无法直观对比同一个户型（如三居）在不同小区之间的表现和买方偏好。

## 4. Current Alternatives

- **贝壳找房 / 链家成交频道**：有成交数据，但维度单一、没有同环比，且无法做跨小区的并排对比图表。
- **透明售房网 / 官方手房网**：网签数据客观，但缺乏标准化户型解析，界面落后，历史图表生成和自主切换体验差。
- **数据研究机构的定期 Excel 报告**：数据滞后，无法根据用户自身关注的小区进行实时组合与多维对比。

## 5. MVP Hypothesis

如果我们可以为用户提供一个“大盘宏观研判 + 局部杭州地图精细选盘 + 跨小区标准化户型多维对比”的直观可视化工具（支持折线、柱状、饼图随时切换以及同环比计算），用户就能更清晰、快捷地挖掘出各板块/小区的价格波动特征，从而做出更理性的资产置业决策。

## 6. Minimum Value Loop

用户进入“大盘看板”研判宏观周期 → 切换至“杭州地图”查看各区均价并在放大后打点定位到具体的意向小区（如西湖区学雅苑） → 将感兴趣的多个小区一键加入对比 → 在“对比分析页”筛选标准化户型（如三居室），生成价格走势对比折线图、成交量对比柱状图及各自成交户型占比饼图 → 查看同比/环比数据，完成小区偏好及性价比差异的科学研判。

## 7. MVP Scope

### P0

- **杭州小区级成交爬虫**：每日自动爬取并解析杭州代表性小区的成交历史（包含成交单价、标准化户型、套数、成交时间）。
- **宏观大盘录入后台**：提供后台管理页面，管理员可通过 Excel 模板一键导入或通过手动表单录入国家统计局 70城指数、全国销售面积、供给/需求端核心宏观数据。
- **局部杭州地图可视化**：实现按行政区/板块聚合的杭州市打点地图，放大后呈现具体小区打点，点击可展开小区量价速览卡片并可一键加入对比。
- **跨小区多维对比看板**：支持添加 2-3 个小区，按标准户型（一/二/三/四居及以上）进行成交量价对比，支持同比、环比计算，并支持折线图、柱状图、饼图（户型占比）自主切换。
- **大盘宏观看板**：展示国家统计局 70城新房/二手房均价指数趋势（支持以100%为环比水平线及同比切换）、单月城市环比涨跌柱状图、全国销售量价图表。

### P1

- 杭州主力楼栋或组团（例如小区一期 vs 二期）的溢价与偏好对比分析。
- 爬虫异常监控及可视化日志管理面板。

### Later

- 房价涨跌微信/邮件订阅通知。
- 板块/小区性价比的自动智能算法推荐。
- 支持基于特定户型图（不仅仅是室数分类）的跨小区偏好分析。

### Out of Scope

- 房屋全自动估值计算（AVM 模型）。
- 基于大数据的房市 AI 走势预测。
- 宏观大盘数据（如央行贷款数据、红线政策数据）的全网自动抓取与清洗。

## 8. Product Surfaces

1. **大盘宏观看板页 (`macro-dashboard`)**：展示 70城价格指数、全国销售面积与销售额图表、供给侧及需求侧各项核心金融与政策指标。
2. **杭州局部地图页 (`hz-map-view`)**：直观的杭州市地图，具备行政区聚合展示、缩放显示小区标点、点击小区弹窗/抽屉展示精简图表及加入对比按钮。
3. **小区对比分析页 (`community-compare`)**：选择小区与标准化户型，一键切换折线/柱状/扇形图展示量价对比、户型占比及同环比指标。
4. **数据管理与爬虫后台 (`admin-portal`)**：管理员上传大盘 Excel 及监控爬虫运行状态的后台页面。

## 9. Key User Flow

- **大盘周期研判流**：用户进入首页（大盘看板） → 查看 70城新房/二手房环比折线图与供需端数据 → 判断当前市场周期的阶段（筑底、回暖或下行）。
- **地图选盘加入对比流**：切换至“杭州地图”页签 → 通过左侧筛选/搜索栏快速查找或定位意向小区 → 地图缩放，点击小区打点标点（如“柳浪东苑”） → 右侧抽出详情面板，展示简易趋势，点击“加入对比”按钮。
- **小区精细对比分析流**：进入“对比分析”页签 → 自动加载已选小区列表 → 勾选户型大类（如“三室”）及对比时间跨度 → 系统计算并渲染均价趋势折线图、成交套数柱状图、标准户型成交构成饼图，以及详细的同环比表格。

## 12. Success Signals

- 杭州代表性小区的成交量价数据能够正常按日自动抓取、清洗并分类为标准户型录入数据库。
- 管理员上传大盘 Excel 后，系统能 100% 正确解析并刷新 70城折线图，折线图需包含 100% 作为环比的对比水平线。
- 用户能够在对比页中无阻碍添加 2 个不同的小区，并成功通过折线图、柱状图、饼图切换比对指定户型（如三居）的均价走势与占比。
