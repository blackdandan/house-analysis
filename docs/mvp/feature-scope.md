# Feature Scope

本文件用于明细和追踪 MVP 功能范围的具体模块。关于产品方向的修改，必须同步至唯一权威主文档 `MVP.md`。

## P0 (MVP 核心交付范围)

| Feature (功能模块) | User Value (用户价值) | Acceptance Signal (验收标志) | Notes (说明) |
|---|---|---|---|
| **全国 70城指数图表** | 研判全国新房/二手房的宏观周期趋势。 | 1. 折线图显示 70城二手房和新房的指数走势；<br>2. 支持同比、环比（以 100% 为水平基准线）切换。 | 数据来自国家统计局，按月更新。 |
| **单月 70城涨跌柱状图** | 快速对比不同城市间的价格分化和抗跌表现。 | 柱状图展示 70 城在选择月份的价格环比涨跌百分比。 | 横轴城市，纵轴涨跌幅。 |
| **全国销售面积与销售额** | 了解全国房地产市场的资金面与交易规模。 | 销售面积以柱状图展示，同比增速以折线图叠加在同一图表上。 | 销售额以顶部指标卡呈现。 |
| **大盘供需基本面看板** | 从资金、新开工、租售比等多维度综合分析市场。 | 提供“需求端”与“供给端”页签：<br>1. 展示贷款、房价收入比、租售比折线图；<br>2. 展示三道红线分布饼图、新开工与到位资金折线图。 | 字段应 100% 对应用户提出的贷款、租售比、三道红线等宏观指标。 |
| **杭州地图行政区聚合** | 快速了解杭州各行政区的均价及活跃度，避免卡顿。 | 地图默认以行政区（西湖区、拱墅区等）标出均价与成交套数，不支持单小区打点。 | 优化前端加载性能。 |
| **小区地图打点与侧栏** | 精准定位到感兴趣的小区，并查看简易画像。 | 放大地图后呈现小区标点，点击任意小区（如学雅苑）侧边栏/弹窗滑出该小区基本均价和成交量图表，并带有“加入对比”按钮。 | 支持小区名称模糊搜索定位。 |
| **跨小区标准化户型对比** | 解决无法跨盘比价、无法对比同一户型偏好差异的痛点。 | 支持添加 2 个及以上小区，可筛选标准户型大类（如三居），展示均价趋势折线图与套数柱状图。 | 计算并展现各自的同比、环比变化数值。 |
| **图表类型自主切换** | 满足用户不同数据洞察的直观偏好。 | 在小区对比图表上方提供切换按钮，用户可一键将对比图表在“折线图”、“柱状图”、“饼图（看户型占比）”之间切换。 | 所有图表数据需保持强一致联动。 |
| **大盘数据 Excel 上传** | 降低开发成本，简易维护低频宏观数据。 | 管理后台页面提供标准 Excel 模板下载与上传解析接口，上传后立即刷新大盘数据库。 | 提供手动修改数据的表单兜底。 |
| **杭州小区数据抓取引擎** | 自动化录入，保障杭州成交数据的时效性。 | 爬虫引擎每天定时运行，抓取并清洗杭州代表性小区的网签及挂牌成交数据，自动按一/二/三/四居大类归档。 | 抓取杭州站成交数据。 |

## P1 (下阶段优化，若开发资源极充沛则可提入一期)

| Feature (功能模块) | Reason To Include If Cheap | Notes |
|---|---|---|
| **主力楼栋/组团溢价分析** | 部分大型小区一期与二期、不同楼栋（如沿马路 vs 临河）价差极大，用户有精细化比价需求。 | 需要爬虫增加抓取和解析房源成交详细文本中的楼栋字段。 |
| **数据同步异常邮件报警** | 爬虫抓取源平台改版可能导致数据录入失败，需及时通知管理员。 | 简易的异常捕获与 SMTP 邮件发送机制。 |

## Later (后续版本规划)

| Feature (功能模块) | Why Later |
|---|---|
| **微信/短信降价订阅** | 偏向于用户触达与留存机制，而非核心置业研判价值闭环。开发涉及短信服务商和微信模板消息对接。 |
| **小区性价比智能算法推荐** | 在没有积累足够丰富的小区底层画像（学区、地铁距离、物业星级）前，纯算法推荐容易失准。 |
| **相似特定户型偏好对比** | 比如跨小区的“三室二厅二卫双阳台”特定户型解析，依赖爬虫对户型图或详细描述做深度提取。 |

## Out Of Scope (本产品边界外，不予考虑)

| Feature (功能模块) | Why Excluded |
|---|---|
| **房产在线自动估值** | AVM（自动估值模型）需要极强的机器学习能力和多维评估因子，不属于数据可视化工具范围。 |
| **未来房市走势 AI 预测** | 房价走势涉及宏观政策、金融环境等复杂非线性变量，AI 预测的准确性极难控制。 |
| **宏观数据全网爬取** | 宏观金融数据来源极广且无统一结构，全网爬虫的开发与维护成本显著高于“Excel 定期导入”。 |
