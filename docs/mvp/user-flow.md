# User Flow

本文件详细描述了用户在系统中的交互路径、页面跳转关系以及关键异常/空数据路径。

## Primary Flow (主业务流：从宏观研判到微观比盘)

用户首先进入大盘看板，对全国的宏观价格与供需走势进行基本面研判。随后切换至杭州地图，直观查看各区域均价并定位意向小区，将其加入对比池。最后进入小区对比页，筛选标准化户型并进行图表多维切换与同环比透视，完成置业决策辅助。

## Flow Steps

| Step | User Action | System Response | Page Or State |
|---|---|---|---|
| 1 | 用户输入网址打开系统。 | 系统默认加载大盘看板，渲染70城新房/二手房指数趋势图、全国新房面积/销售额图及供需面板。 | 大盘宏观看板页 (`macro-dashboard`) [默认加载状态] |
| 2 | 用户研判完宏观周期后，点击顶部导航的“杭州地图”。 | 系统展示杭州市地图，默认以行政区（西湖区、拱墅区等）为维度，展示聚合后的成交均价和成交套数。 | 杭州局部地图页 (`hz-map-view`) [行政区聚合状态] |
| 3 | 用户双击地图放大，或在左上角搜索栏输入小区名称（如“学雅苑”）。 | 系统平移并缩放地图到指定区域，地图打点呈现出具体小区标点（带有颜色深浅表示均价高低）。 | 杭州局部地图页 (`hz-map-view`) [小区打点状态] |
| 4 | 用户点击“学雅苑”的地图标点。 | 系统在右侧/底部拉出“小区基本画幅”抽屉，展示该小区的最新均价、近期成交套数，并提供“加入对比”按钮。 | 杭州局部地图页 (`hz-map-view`) [小区详情抽屉展开] |
| 5 | 用户点击“加入对比”按钮。 | 系统将该小区暂存进“全局对比池”，地图界面右上角悬浮球的对比数量由 `[0]` 变为 `[1]`。 | 杭州局部地图页 (`hz-map-view`) [对比池更新] |
| 6 | 用户以同样方式在地图上选择“翡翠城”、“武林壹号”并点击“加入对比”；随后点击右上角悬浮球或顶部“小区对比”导航。 | 系统跳转至对比页面，自动将这 3 个小区预载在对比池中。 | 小区对比分析页 (`community-compare`) [多小区载入状态] |
| 7 | 用户在顶部多选下拉浮层中，看到 3 个小区均已勾选。用户筛选对比户型为“三居”，对比跨度为“近1.5年”。 | 系统重算三小区近1.5年三居室的成交数据，折线图区渲染出红（学雅苑）、蓝（翡翠城）、紫（武林壹号）三条趋势折线；对照表自适应动态生成 3 列数据。 | 小区对比分析页 (`community-compare`) [多线/多列渲染就绪状态] |
| 8 | 用户将鼠标悬停在图表区或点击“切换为柱状图”。 | 系统实时把均价趋势渲染为“三柱并排”的柱状图，并在鼠标移动时计算最近邻点，动态弹出毛玻璃样式的 Tooltip 框展示具体数值和环比值。 | 小区对比分析页 (`community-compare`) [悬浮 Tooltip 状态] |

## Alternate Flows (分支流)

### 1. 快速快捷对比流
用户跳过地图浏览阶段，直接通过顶部导航进入 `小区对比页` → 点击顶部的小区多选框下拉菜单 → 从列表中直接勾选“朝晖六区”、“金沙湖壹号”等多个目标小区（最多 4 个） → 图表和表格自适应增加对应的趋势线和对比列。

### 2. 宏观大盘 Excel 导入流 (管理员交互)
管理员进入数据后台 (`admin-portal`) → 点击“下载大盘数据模板.xlsx” → 录入当月最新的 70城指数、中长期贷款、到位资金等低频宏观数据 → 点击“上传 Excel”按钮并选中文件 → 系统校验并解析文件成功，提示“数据导入完成，影响 24 个指标” → 管理员返回前台，大盘宏观看板已渲染出当月最新折线趋势。

### 3. 大盘看板折线悬浮 Tooltip 交互流 (高保真交互)
用户在大盘看板页面浏览 70城二手房环比折线图 → 将鼠标移动到图表的任意区域 → 系统动态捕获鼠标 X 坐标，寻找最近的月份节点（如 2025-12） → 渲染半透明 Tooltip，在鼠标旁边展示当前月份、指数值、环比增幅百分比，并伴有对应折线节点的圆形亮光效果。

## Failure Or Empty Paths (异常与空数据路径)

### 1. 爬虫未覆盖小区搜索 (地图空状态)
* **场景**：用户在杭州地图搜索框输入一个极其冷门、当前爬虫库未收录的小区。
* **系统响应**：搜索框下方下拉框提示“未找到该小区数据，已为您提交数据采集申请”。地图不平移，左侧展示“空搜索反馈”面板，告知用户“预计 24 小时内完成爬虫同步”。

### 2. 对比小区无同类户型 (对比图表空状态)
* **场景**：用户对比“学雅苑”（均为大户型）和“朝晖九区”（均为小户型老破小），并在户型中筛选了“四居及以上”。
* **系统响应**：图表区域不展示空白页面，而是呈现美观的“无重合数据空状态”插图，提示：“当前筛选时间段与户型下，对比小区无成交记录。建议重新选择户型大类（如：二居）或扩大时间范围。”

### 3. 管理员 Excel 模板文件损毁/格式错配 (上传异常)
* **场景**：管理员上传了一个工作表名称被篡改、或者关键字段（如“三道红线房企数”）被整行删除的 Excel 文件。
* **系统响应**：后台上传组件停止解析，进度条变红，并弹出错误提示框：“导入失败！未检测到‘三道红线’指标行。请不要修改 Excel 模板的结构，重新下载模板录入后上传。”

## Visual Page Map (视觉页面映射)

| Page (页面) | Purpose (核心目的) | Key States (关键交互状态) |
|---|---|---|
| **`macro-dashboard`** | 研判全国房地产周期大趋势。 | - **默认就绪状态**：展示多维折线/柱状/饼图。<br>- **折线悬停状态 (Tooltip)**：鼠标悬浮折线时，动态高亮节点并滑出数据卡片。 |
| **`hz-map-view`** | 在地图上直观搜寻、比价和定位小区。 | - **行政区聚合状态**：展示西湖、拱墅等各区热力与套数。<br>- **小区散点打点状态**：地图放大后的小区标点。<br>- **小区抽屉卡片状态**：右侧滑出展示小区量价趋势与加入对比按钮。 |
| **`community-compare`** | 多角度、多维度切换比对小区性价比和户型偏好。 | - **对比空状态**：未选择任何小区，提示“请在上方添加小区以开始对比”。<br>- **多小区对比状态 (2~4个)**：多条趋势折线/多组并立柱体/多个饼图自适应排布，对照表自动生成多列，鼠标悬停渲染交互 Tooltip。 |
| **`admin-portal`** | 管理员维护大盘数据与查看爬虫状态。 | - **数据上传状态**：拖拽上传 Excel 与进度反馈。<br>- **日志监控状态**：展示爬虫每日成功率、抓取小区总数与异常报警。 |
