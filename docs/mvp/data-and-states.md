# Data And States

本文件描述产品层面的核心数据实体模型、关键交互界面在不同场景下的页面状态表现，以及为视觉预览（Preview）所制定的假数据填充规范。本文件不做数据库表设计和 API 契约定义。

## Product Entities (产品核心实体)

| Entity (实体名称) | Product Meaning (产品业务含义) | Example Fields (关键字段示例) |
|---|---|---|
| **`MacroIndicator`**<br>(大盘宏观指标) | 记录全国范围的月度/年度房地产宏观统计指标，供宏观研判使用。 | - `month`: 统计月份 (如: "2026-05")<br>- `index70New`: 70城新房均价指数 (环比/同比)<br>- `index70Second`: 70城二手房均价指数 (环比/同比)<br>- `totalSalesArea`: 全国累计新房销售面积 (万㎡)<br>- `totalSalesAmount`: 全国累计新房销售额 (亿元)<br>- `personalLoans`: 住户新增中长期消费贷款 (亿元)<br>- `rentToSellRatio`: 典型城市平均租售比<br>- `rentalYield`: 平均租金收益率<br>- `debtToIncomeRatio`: 居民债务收入比<br>- `threeRedLinesDistribution`: 房企三道红线分类分布 (绿/黄/橙/红档数量)<br>- `newConstructionArea`: 住宅新开工面积 (万㎡)<br>- `realizedCapital`: 开发投资实际到位资金 (亿元) |
| **`CommunityInfo`**<br>(杭州小区基本画像) | 描述杭州本地单个小区的地理分布、挂牌热度与基础均价画像。 | - `communityId`: 小区唯一编号<br>- `name`: 小区名称 (如: "学雅苑")<br>- `district`: 所属行政区 (如: "西湖区")<br>- `subDistrict`: 所属板块 (如: "文教")<br>- `latitude` / `longitude`: 经纬度坐标<br>- `mainRoomType`: 主力标准化户型 (如: "三居")<br>- `activeListingCount`: 当前在售挂牌套数<br>- `averagePrice`: 当前挂牌成交均价 (元/㎡) |
| **`CommunityTransaction`**<br>(小区成交历史) | 由杭州小区数据爬虫抓取并标准化的历史实际成交记录。 | - `transactionId`: 成交编号<br>- `communityId`: 关联的小区编号<br>- `transactionDate`: 成交日期 (如: "2026-05-18")<br>- `price`: 成交单价 (元/㎡)<br>- `standardRoomType`: 标准化户型分类 (一居 / 二居 / 三居 / 四居及以上)<br>- `volume`: 当次成交套数 (通常为 1) |

## Page States (页面状态矩阵)

| Page (页面) | Default State (默认状态) | Empty State (空数据状态) | Error State (异常状态) | Success State (成功状态) |
|---|---|---|---|---|
| **`macro-dashboard`**<br>(大盘宏观看板) | 自动渲染加载最新的 70城二手房/新房均价折线趋势、全国销售双轴图及供需数据面板。 | 当系统中未录入任何大盘宏观数据时，所有图表位置显示灰色骨架图并提示：“暂无宏观指标数据，请管理员从后台上传数据 Excel”。 | 数据接口加载超时或损坏时，顶部呈现全局红色警告横幅：“大盘数据加载失败，请检查网络并刷新重试”。 | 导入最新 Excel 数据后，图表瞬间无缓存重绘刷新，并在顶部提示：“大盘宏观数据已更新至 2026年6月”。 |
| **`hz-map-view`**<br>(杭州局部地图) | 地图默认定位到杭州中心区域，呈现西湖区、拱墅区等行政区级别的成交聚合信息气泡。 | 用户在搜索框内搜索了一个库中未收录的冷门小区时，地图不平移，左下角滑出卡片提示“未匹配到小区，已自动为您提交每日采集队列”。 | 地图图层加载失败时，地图区域渲染为浅灰色，中心提示：“底图服务加载失败，请检查您的网络连接”。 | 放大地图至 Level 14 成功展示小区打点；点击小区侧边抽屉流畅展开，呈现量价小折线图和一键对比按钮。 |
| **`community-compare`**<br>(小区对比分析) | 顶部有两个带 “+” 号的空对比槽，下方大面积展示引导文案：“请在上方搜索或在地图中添加小区以开启跨盘量价对比”。 | 当对比的两个小区在当前筛选的时间段或户型大类下（例如四居及以上）无任何成交历史时，图表隐藏，呈现插图并提示：“该户型下暂无重合历史成交，请重新选择户型（如: 三居）”。 | 对比计算过程发生异常，图表区域呈现灰色遮罩并提示：“数据处理发生异常，请移除对比小区并重新添加”。 | 成功渲染出两小区的均价对比折线图、成交套数柱状图、户型占比饼图，且同环比表格数据计算完整呈现。 |
| **`admin-portal`**<br>(数据导入后台) | 展示 Excel 文件拖拽上传区域（带虚线框）和简易的杭州爬虫每日抓取状态统计表。 | 爬虫抓取队列为空，日志列表提示“暂无抓取同步日志”。 | 上传了格式被破坏的 Excel 文件时，拖拽上传区域变红，振动提示并弹窗：“解析失败，导入的 Excel 缺失‘住户中长期贷款’行”。 | 上传正确模板后，进度条变为 100% 绿色，弹窗提示：“大盘数据解析成功！24 条指标已写入大盘看板”。 |

## Mock Data Requirements (视觉预览假数据规范)

为了使生成的静态视觉预览页面能展现出高保真、可信且真实的交互效果，`preview/mvp/mock-data.js` 的数据必须遵守以下要求：

1. **时间跨度**：大盘宏观数据必须包含 **2023年1月至2026年6月** 的完整月度数据，以保证同比、环比折线图有足够的数据长度（至少 36 个月）。
2. **重点小区画像**：必须内置至少 3 个特色鲜明的杭州代表性小区：
   * **小区 A：学雅苑**（西湖区文教板块）：高端学区房，均价 6.5万~7.5万，三居占比高，价格相对抗跌。
   * **小区 B：翡翠城**（余杭区未来科技城板块）：近郊刚需及改善盘，均价 3.5万~4.5万，二居和三居并重，随大盘波动较大。
   * **小区 C：柳浪东苑**（上城区西湖景区板块）：顶级豪宅/老牌高端，均价 9万~11万，四居占比高，成交量小但单价高。
3. **数据强一致性**：每个小区的月度成交记录、标准化户型（一居、二居、三居、四居及以上）的套数构成、以及计算得出的同比/环比数值，必须是数学上可校验一致的，不得随意填入冲突数据。
4. **技术边界**：所有假数据必须以 JSON 格式声明于 `preview/mvp/mock-data.js`，通过全局变量或 ES6 模块供 `app.js` 使用。**严禁使用任何外部 fetch/XMLHttpRequest 异步请求读取本地或远程文件**。
